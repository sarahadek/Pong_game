# Pong Game 🏓

## Description
A classic Pong game built in Python using the Turtle module.

## Features
- Two-player paddle controls
- Ball movement and collision
- Score tracking

## How to Run
Run `main.py` in Python 3.11 or higher.

## What I Learned
- Object-Oriented Programming
- Event-driven programming with Turtle
- Game loop and collision detection
